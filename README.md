# Laravel Tipi Support

Shared, framework-agnostic support primitives used by Laravel Tipi packages.

## Requirements

- PHP 8.5+

## Installation

```bash
composer require laravel-tipi/support
```

## Included utilities

- `Tipi\Support\Locale` — immutable locale value object.
- `Tipi\Support\Enums\TextDirection` — left-to-right and right-to-left text direction.
- `Tipi\Support\Data\DataTransferObject` — minimal DTO contract.
- `Tipi\Support\Arr\ArrayHelper` — shared array utilities.
